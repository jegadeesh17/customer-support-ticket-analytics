How It Works

  1. Tier 1 scores every ticket instantly A priority classifier (82.1% held-out accuracy) and a resolution-time regressor (R² 0.7185) read the ticket text and its tabular context.
  2. The gate decides whether Tier 2 runs A ticket escalates when Tier 1 confidence is below 0.67, estimated resolution exceeds 185 h, or the customer is in the Enterprise segment.
  3. Tier 2 diagnoses and drafts a reply An LLM provider chain with heuristic fallback scores frustration, names a root cause, recommends an action and drafts a response. If no provider answers, the heuristic fallback does.
